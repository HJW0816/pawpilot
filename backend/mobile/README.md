# PawPilot 휴대폰 앱 — 0.3 개발판

2026-11-04 · 반효준 · 박현진

설치형 모바일 웹앱(PWA)으로 구현했다. Android/iOS 네이티브 휴대폰 앱 또는 스토어 배포본은 아니다. 차량용 APK는 별도다.

## 구현 범위

- 발견: 휴게소·카페·공원·숙소·식당·기타 장소 검색, 동반 가능한 동물·이용 조건 표시, 이용자 장소 등록.
- 이야기: 실제 방문일·동반 동물·별점·본문 공유, 본인 후기 수정/삭제, 신고 시 검토 전 숨김. 아직 실제 이용자 후기 데이터는 없다.
- 우리 아이: 촬영/앨범 선택 입력, 768px 이하 JPEG 변환, 위치 메타데이터 제거, 비공개 프로필 저장. 강조색과 바탕을 미리 보고 설정한다. 밝아 글씨 대비가 부족한 강조색은 거부한다.
- 차량: 15분 일회용 코드로 연결하고 저장한 프로필이나 선택 장소만 전송한다. 새로고침 시 같은 브라우저의 유효한 연결을 복원한다.
- 차량 앱: 전경에서 수신을 확인하며 정차·UX 허용 상태에서만 확인창을 보여 준다. 프로필은 확인 후 적용하고 장소는 확인 후 현대 내비 검색을 요청한다. 검색 요청은 경로 생성/목적지 설정 성공을 의미하지 않는다.

## 로컬 실행

프로젝트 최상위에서 Node 22 이상으로 실행한다.

```sh
node backend/server.mjs
```

컴퓨터에서 `http://127.0.0.1:8787/mobile`을 연다. 기본 서버는 loopback에만 바인딩하므로 휴대폰에서 컴퓨터 IP로 접속할 수 없다. 오프라인 저장은 제공하지 않는다.

## 실제 휴대폰과 차량 연결에 필요한 설정

1. 접근이 통제된 HTTPS 서버와 게이트웨이를 준비한다. `PAWPILOT_PUBLIC_ORIGIN=https://승인된-호스트`를 정확한 origin으로 설정하고 reverse proxy로 loopback 서버에 연결한다. 현재 로그인/복구·운영자 관리·공개 서비스 인증은 미구현이다. 이 개발 서버를 그대로 공개 배포하지 않는다.
2. 같은 HTTPS origin을 차량 빌드의 `-PpawpilotCompanionUrl=https://승인된-호스트`로 지정한다. 기본값은 비어 있으며 이번 차량 APK에도 실제 서버 주소가 포함되지 않는다.
3. 휴대폰에서 HTTPS `/mobile`을 열고 프로필을 저장한다. 브라우저가 지원하면 홈 화면에 추가한다.
4. 정차한 차량에서 설정 → 휴대폰 연결을 열고 표시된 코드를 휴대폰 차량 탭에 입력한다.
5. 휴대폰에서 프로필 또는 장소를 보내고 차량에서 확인한다. 장소는 내비 검색 결과에서 위치·방향을 확인하고 경로를 선택한다.

촬영 입력은 모바일 브라우저의 파일 선택/capture 기능이다. 기종·브라우저별 카메라 UI와 홈 화면 설치는 실기 검증이 필요하다.

## 데이터와 운영 범위

프로필·장소·후기는 `backend/data/private/mobile.json`에 저장한다. `PAWPILOT_MOBILE_DATA`로 경로를 지정할 수 있다. 브라우저의 HttpOnly 기기 쿠키로 소유권을 확인하는 비공개 파일럿이며 정식 계정 시스템은 아니다. 브라우저 데이터를 지우면 기존 프로필/후기 접근을 복구할 수 없다. 사진은 커뮤니티 응답에 포함하지 않는다.

연결 토큰과 대기 항목은 서버 메모리에만 존재하고 만료/재시작 시 사라진다. 전송 상태는 대기·프로필 적용·내비 검색 요청·취소·실패를 구별한다. 차량 종료나 통신 단절에는 적용이 지연될 수 있다. 주행 중 운전자 휴대폰 조작을 유도하지 않는다.

공식 카탈로그는 기존 앱 자료와 출처일을 그대로 표시한다. 이용자 등록 장소는 미확인으로 구분한다. 강아지 놀이터 정보로 고양이 입장을 추정하지 않는다. 새 커뮤니티 후기는 기존 AI 추천 근거 저장소에 자동 편입하지 않는다. 동의 범위, 검토, 장소 ID 매핑을 갖춘 연계가 후속 과제다.

## 검증 결과와 남은 작업

- 서버/핸들러 테스트 13개 통과: 사진 전달, 소유권, 수정·삭제·신고, 연결 역할, 만료, 중복 확인 응답, 쿠키·origin 검증 등. 네트워크 소켓 없이 직접 핸들러를 호출한 검사다.
- 차량 Kotlin 컴파일, 기존 회귀검사 6종, `assembleRelease`·`lintRelease` 성공. lint 0 errors / 30 warnings.
- 차량 0.3.0 APK는 검토용 키로 서명 및 검증했다. 기존 0.2.0 전달본과 설치된 사용자 데이터는 보존했다. 새 APK 설치·실행 검증은 하지 않았다.
- 실행 환경에서 서버 listen이 EPERM으로 차단되고 직접 Chrome 실행도 실패해 브라우저 UI 시험을 완료하지 못했다. `validation/2026-11-04-mobile/browser-check.mjs`는 준비된 미실행 시나리오다. 정적 visual-preview는 화면 검토용 fixture이며 동작 증거가 아니다.
- 실제 휴대폰 촬영·사진 업로드, HTTPS 서버 배포, 차량 수신·정차 제약, 실제 내비 검색과 경로 선택을 함께 검증해야 한다.
- 후속 개발: 정식 로그인/복구, 데이터 삭제·보존 정책, 운영자 신고 검토, 장소 운영 조건 갱신, 장소 중복 병합, 실제 좌표/POI 매칭, 커뮤니티 근거 기반 AI 추천 연결.
